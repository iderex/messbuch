# NNNN Short title, as a statement of the question

Copy this file to `docs/decisions/NNNN-slug.md`, take the next free number, and
replace every heading's contents. Delete this paragraph. The seven parts and
the numbering rule are set out in
`docs/decisions/0001-how-decisions-are-recorded.md`; a record missing a part is
incomplete, and nothing in this repository refuses one, so the reviewer is what
catches it.

## Question

What was undecided, written so somebody who does not already know the answer
can see what was at stake.

## Options considered

The options genuinely on the table, including the one that was chosen. One
entry here means no decision was taken.

## What each option costs

Per option, one paragraph each. Write the cost of the chosen option as plainly
as the cost of the rejected ones.

## Choice

What was decided, stated so a reader can tell whether a given change conforms
to it.

## Reasons

Why this option beat the others, referring to the costs above rather than
repeating them.

Where the record claims something a machine refuses, name the check. Where it
claims something nothing refuses, write `PROSE, NOT ENFORCEMENT` here with the
issue that owes the mechanism, or say that no mechanism is possible and why.

## Date

YYYY-MM-DD

## Reversal condition

What would have to become true for this decision to be looked at again. If no
condition can be named, say so and say why. Do not delete this heading.
